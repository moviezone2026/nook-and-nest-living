# Nook & Nest Living — Static Blog Starter

Includes responsive homepage, 10 English starter articles, About/Contact/Privacy pages, CSS, robots.txt, sitemap.xml, SEO checklist, Pinterest copy for 10 pins, and one editable SVG pin design.

## Publish with GitHub + Netlify
1. Create a GitHub repository, e.g. `nook-and-nest-living`.
2. Upload the *contents* of this folder to the repository root.
3. Replace the placeholder in contact.html with an email you check. Customize privacy.html.
4. Visit https://app.netlify.com/ → Add new project → Import an existing project → connect GitHub → select repository.
5. For plain HTML, leave Build command blank and set publish directory to `.` if asked.
6. Deploy and copy the free `https://your-site-name.netlify.app` URL.
7. Replace `REPLACE-WITH-YOUR-SITE.netlify.app` in sitemap.xml and robots.txt with your actual Netlify subdomain, then commit the changes.
8. Test the homepage and all article links on mobile.
9. In Google Search Console, verify the site and submit `https://YOUR-SITE-NAME.netlify.app/sitemap.xml`.

## Pinterest
Use PINTEREST-PACK.md. Recommended canvas is 1000 × 1500 px (2:3). Link each pin to its corresponding live article URL. The starter SVG is in assets/pins/.
